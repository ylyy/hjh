# 大众点评"免费试"自动点击脚本

## 📱 功能说明

自动点击大众点评App中"免费试"页面的所有申请按钮，帮你一键申请所有免费试用活动。

## 🔧 环境要求

- **Android 手机**（iOS暂不支持）
- **Android 7.0+** 系统版本
- **AutoX.js** 或 **Auto.js Pro** App

## 📥 安装步骤

### 第一步：安装 AutoX.js

AutoX.js 是开源免费的自动化工具：

**下载地址：**
- GitHub: https://github.com/kkevsekk1/AutoX/releases
- 选择最新版本的 `.apk` 文件下载安装

### 第二步：授予权限

安装后需要授予以下权限：

1. **无障碍服务权限**（必须）
   - 打开手机 `设置` → `无障碍` → 找到 `AutoX.js` → 开启

2. **悬浮窗权限**（推荐）
   - 打开手机 `设置` → `应用管理` → `AutoX.js` → `悬浮窗` → 开启

3. **存储权限**
   - 用于读取脚本文件

### 第三步：导入脚本

1. 将 `dianping_free_trial.js` 文件传输到手机
2. 打开 AutoX.js App
3. 点击右上角 `+` 号 → `导入` → 选择脚本文件
4. 或者直接将脚本代码复制粘贴到新建脚本中

## 🚀 使用方法

1. 打开**大众点评** App
2. 进入**"免费试"**页面
   - 路径：首页 → 搜索"免费试" 或 "我的" → "免费试"
3. 切换到 AutoX.js，**运行脚本**
4. 脚本会自动：
   - 查找所有"免费申请"按钮
   - 逐个点击申请
   - 自动滑动加载更多
   - 处理弹窗确认

## ⚙️ 配置参数

可以在脚本顶部修改配置：

```javascript
const CONFIG = {
    clickDelay: 1500,      // 点击间隔(毫秒)，太快可能被检测
    scrollDelay: 1000,     // 滑动后等待时间
    maxScrollCount: 50,    // 最大滑动次数
    // ... 其他配置
};
```

## ⏹️ 停止脚本

- 按**音量+键**可随时停止脚本
- 或在 AutoX.js 中点击停止按钮

## ⚠️ 注意事项

1. **账号安全**：建议适当增加 `clickDelay` 时间，避免操作过快触发风控
2. **网络环境**：确保网络稳定，否则可能加载失败
3. **页面适配**：如果大众点评更新界面，可能需要调整关键词
4. **合理使用**：请遵守平台规则，合理使用自动化工具

## 🔄 如果脚本无法正常工作

可能的原因和解决方法：

1. **无障碍服务被关闭**
   - 重新开启无障碍服务

2. **大众点评更新了界面**
   - 修改 `applyKeywords` 中的按钮文字

3. **按钮找不到**
   - 使用 AutoX.js 的"布局分析"功能查看实际的按钮文字
