# AI生产力教练 - 架构设计文档

## 1. 系统概述

AI生产力教练是一个基于双Agent AI架构的智能生产力管理系统，通过监控用户行为、智能干预和成就激励，帮助用户建立更好的工作生活习惯。

## 2. 核心设计理念

### 2.1 双Agent架构

系统采用两个协作的AI Agent：

#### 策划Agent (Planner Agent)
- **职责**: 长期规划和战略决策
- **功能**:
  - 分析用户行为模式（周/月维度）
  - 制定个性化目标和策略
  - 评估干预效果并优化
  - 生成分析报告

#### 导演Agent (Director Agent)
- **职责**: 实时响应和战术执行
- **功能**:
  - 监控应用使用事件
  - 即时决策是否干预
  - 选择干预方式和时机
  - 处理用户响应

### 2.2 设计优势

相比传统单一AI系统，双Agent架构提供：

1. **职责分离**: 策略规划与执行分离，各司其职
2. **时间维度**: 长期分析 + 短期响应
3. **协作增强**: 策划制定策略，导演执行优化
4. **适应性强**: 根据效果反馈动态调整

## 4. 核心模块设计

### 4.1 Android监控模块

**技术栈**: Kotlin + Jetpack Compose + WorkManager

**核心组件**:
- `AppMonitorService`: 前台服务，持续监控应用
- `UsageStatsManager`: 获取应用使用统计
- `ApiClient`: 与后端通信

**监控流程**:
1. 每2秒检查前台应用
2. 识别娱乐应用
3. 上报到后端
4. 接收并展示AI干预

## 5. 数据模型

### 5.1 用户行为表 (user_behavior)
```sql
CREATE TABLE user_behavior (
    id INTEGER PRIMARY KEY,
    timestamp DATETIME,
    app_name TEXT,
    app_category TEXT,
    duration INTEGER,
    intervention_result TEXT
);
```

### 5.2 目标表 (goals)
```sql
CREATE TABLE goals (
    id INTEGER PRIMARY KEY,
    goal_type TEXT,
    target_value REAL,
    current_value REAL,
    start_date DATE,
    end_date DATE,
    status TEXT,
    description TEXT
);
```

```sql
CREATE TABLE achievements (

);
```

## 6. AI决策流程

### 6.1 实时干预流程

```
用户打开应用
    ↓
[Android] 检测到事件
    ↓
[Android] 上报到后端
    ↓
[Director] 接收事件
    ↓
[Director] 评估是否干预
    ├─ YES → 选择策略 → 执行 → 返回响应
    └─ NO  → 仅记录 → 继续观察
    ↓
[Android] 显示通知/提醒
    ↓
用户响应
    ↓
[Director] 记录效果
    ↓
[Planner] 异步分析（后台）
```

### 6.2 策略优化流程

```
[Planner] 每日定时分析
    ↓
聚合最近N天数据
    ↓
识别模式和问题
    ↓
评估现有策略效果
    ↓
生成优化建议
    ↓
更新干预策略
    ↓
[Director] 读取新策略
    ↓
应用到实时决策
```

## 7. 安全和隐私

### 7.1 数据安全
- 所有数据本地存储（SQLite）
- 不上传敏感信息到云端
- 支持数据导出和删除

### 7.2 权限管理
- 使用统计权限（必需）
- 通知权限（推荐）
- 不收集其他敏感权限

## 8. 性能优化

### 8.1 Android端
- 使用WorkManager避免频繁轮询
- 冷却机制防止过度干预
- 本地缓存减少网络请求

### 8.2 后端
- 异步处理分析任务
- 数据库索引优化
- API响应缓存
