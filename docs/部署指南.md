## 后端部署

### 步骤1: 安装Python依赖

```bash
cd backend
pip install -r requirements.txt
```

### 步骤2: 初始化数据库

```bash
mkdir -p data
python -c "from agents.planner_agent import PlannerAgent; PlannerAgent()"
```

数据库将自动创建在 `data/coach.db`

### 步骤3: 启动服务器

#### 开发模式
```bash
cd backend/api
python server.py
```

服务器将在 `http://localhost:8000` 启动

#### 生产模式（使用Gunicorn）
```bash
pip install gunicorn
gunicorn -w 4 -k uvicorn.workers.UvicornWorker api.server:app --bind 0.0.0.0:8000
```

### 步骤4: 验证部署

访问 http://localhost:8000 应该看到：
```json
{
  "status": "running",
  "service": "AI生产力教练",
  "agents": {
    "planner": "策划Agent",
    "director": "导演Agent"
  }
}
```

### 步骤5: 查看API文档

访问 http://localhost:8000/docs 查看完整API文档

## Web控制台部署

### 步骤1: 安装依赖

```bash
cd web-console
npm install
```

### 步骤2: 配置后端地址

编辑 `vite.config.js`，确保proxy指向正确的后端地址：

```javascript
export default defineConfig({
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:8000',  // 修改为你的后端地址
        changeOrigin: true,
      }
    }
  }
})
```

### 步骤3: 启动开发服务器

```bash
npm run dev
```

访问 http://localhost:3000

### 步骤4: 构建生产版本

```bash
npm run build
```

生成的文件在 `dist/` 目录，可以部署到任何静态文件服务器：

#### 使用Nginx部署

```nginx
server {
    listen 80;
    server_name your-domain.com;
    
    root /path/to/dist;
    index index.html;
    
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    location /api {
        proxy_pass http://localhost:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

## Android应用安装

### 方法1: Android Studio开发

#### 步骤1: 打开项目
```bash
# 用Android Studio打开
File -> Open -> 选择 android-app/ 目录
```

#### 步骤2: 配置服务器地址

编辑 `android-app/app/src/main/java/com/aicoach/network/ApiClient.kt`:

```kotlin
// 模拟器访问本机
private const val BASE_URL = "http://10.0.2.2:8000/"

// 真机测试时改为电脑IP
// private const val BASE_URL = "http://192.168.1.100:8000/"
```

#### 步骤3: 连接设备并运行

1. 连接Android手机（开启USB调试）或启动模拟器
2. 点击Android Studio的 Run 按钮
3. 等待构建和安装完成

### 方法2: 构建APK文件

#### 步骤1: 生成Release APK

```bash
cd android-app
./gradlew assembleRelease
```

APK文件位置: `android-app/app/build/outputs/apk/release/app-release.apk`

#### 步骤2: 安装到手机

```bash
adb install app/build/outputs/apk/release/app-release.apk
```

或者直接将APK传输到手机安装

### 步骤3: 授予权限

首次运行需要授予以下权限：

1. **通知权限**: 接收AI提醒
2. **使用统计权限**: 监控应用使用
   - 设置 -> 应用 -> 特殊应用权限 -> 使用情况访问权限
   - 找到"AI生产力教练"并开启

## Docker部署（推荐）

### Docker Compose一键部署

创建 `docker-compose.yml`:

```yaml
version: '3.8'

services:
  backend:
    build: ./backend
    ports:
      - "8000:8000"
    volumes:
      - ./data:/app/data
    environment:
      - PYTHONUNBUFFERED=1
    restart: unless-stopped

  frontend:
    build: ./web-console
    ports:
      - "3000:80"
    depends_on:
      - backend
    restart: unless-stopped
```

启动：
```bash
docker-compose up -d
```

## 云服务器部署

### 推荐配置
- CPU: 1核
- 内存: 1GB
- 存储: 10GB
- 带宽: 1Mbps

### 步骤1: 购买服务器

推荐平台：
- 阿里云ECS
- 腾讯云CVM
- AWS EC2
- DigitalOcean

### 步骤2: 安装依赖

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install python3 python3-pip nodejs npm nginx

# CentOS
sudo yum install python3 python3-pip nodejs npm nginx
```

### 步骤3: 部署后端

```bash
cd /opt
git clone https://your-repo.git
cd backend
pip3 install -r requirements.txt
```

### 步骤4: 配置Systemd服务

创建 `/etc/systemd/system/ai-coach.service`:

```ini
[Unit]
Description=AI Productivity Coach Backend
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/backend/api
ExecStart=/usr/bin/python3 server.py
Restart=always

[Install]
WantedBy=multi-user.target
```

启动服务：
```bash
sudo systemctl enable ai-coach
sudo systemctl start ai-coach
```

### 步骤5: 配置防火墙

```bash
# 开放端口
sudo ufw allow 80
sudo ufw allow 443
sudo ufw allow 8000
```

## 常见问题

### Q1: 后端启动失败

**可能原因**:
- Python版本过低
- 依赖安装不完整
- 端口被占用

**解决方案**:
```bash
# 检查Python版本
python3 --version

# 重新安装依赖
pip3 install -r requirements.txt --upgrade

# 检查端口
lsof -i:8000
```

### Q2: Android应用无法连接后端

**可能原因**:
- 服务器地址配置错误
- 防火墙阻止
- 网络问题

**解决方案**:
1. 确保手机和电脑在同一网络
2. 使用电脑IP而不是localhost
3. 检查防火墙设置
4. 在浏览器测试后端是否可访问

### Q3: 权限授予失败

**解决方案**:
1. 手动进入设置授权
2. 某些定制系统（小米、华为）需要额外设置
3. 确保Android版本 >= 8.0

### Q4: Web控制台无数据

**可能原因**:
- 后端未启动
- API地址配置错误
- CORS问题

**解决方案**:
1. 检查后端是否运行
2. 浏览器开发者工具查看网络请求
3. 确认后端CORS配置正确

## 性能优化建议

### 后端优化
1. 使用Redis缓存频繁查询
2. 数据库定期清理旧数据
3. 启用Gzip压缩

### 网络优化
1. 使用CDN加速静态资源
2. 启用HTTP/2
3. 配置SSL证书（生产环境）

### Android优化
1. 调整监控频率（默认2秒）
2. 限制每日干预次数
3. 使用WiFi时才同步数据
